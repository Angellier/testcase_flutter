# Тестовое задание: экран чата (`room1`)

## Платформа проверки
- Проверка выполнена на **Windows** (`flutter run -d windows`); окружение Android SDK на тестовой машине не настраивалось.

## Принятые решения и ограничения
- **Архитектура и состояние:** использован `ChangeNotifier` без сторонних state-менеджеров; состояние хранится в памяти в одном месте (`ChatController`).
- **Идемпотентность и повтор:** при повторе сохраняется исходный `clientId`, обновляется существующая запись без создания дубля, а на время активного запроса повтор по этому `clientId` блокируется.
- **Ограничения по ТЗ:** история из 6 сообщений для `room1` хранится только в оперативной памяти без локальной БД, пагинации и восстановления после перезапуска; реальный сервер, WebSocket/поток событий, push и звонки не подключались.
